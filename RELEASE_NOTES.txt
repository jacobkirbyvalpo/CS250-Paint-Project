Jacob's Paint Version 0.5.0 - 10/05/2026

Repository: https://github.com/jacobkirbyvalpo/CS250-Paint-Project
Release tag: https://github.com/jacobkirbyvalpo/CS250-Paint-Project/releases/tag/v0.5.0

New Features:
* The program now starts with a blank white canvas.
* File > New (Ctrl+N) opens another blank canvas in a new tab
* Undo (Ctrl+Z) and Redo (Ctrl+Y) under the new Edit menu, built on two stacks, each tab has its own
* Clear Canvas under Edit, with an "are you sure" check
* Resizing the canvas can be undone
* Line tool shows a live preview while dragging
* Right triangle tool
* Regular polygon tool, with a Sides box in the toolbar to pick the number of sides (3 to 100)
* Diamond tool
* Text tool, click the image and type the text to add, uses the current color, the width slider sets the size
* Select tool, drag to mark an area with a dashed box that is not saved into the image
* Copy (Ctrl+C) copies the selected area, works between tabs
* Paste tool, the copied piece follows the mouse while dragging and stays on release
* Move tool, the selected piece is lifted out and follows the mouse while dragging
* All new shapes, paste, and move show a live preview and can be undone
* New tabs that have never been saved are named Untitled

Known Issues:
* Grabber only picks up a color while dragging, a single click does nothing
* Dragging the grabber off the edge of the canvas causes an error
* In the unsaved changes dialog, clicking Save and then cancelling the Save As window still closes the tab
* Clicking a tool button that is already selected unselects it, but the tool stays active
* Text has no preview before it is placed
* Paste is a toolbar tool, there is no Ctrl+V
* Pencil looks mostly solid when Dashed is on
* The toolbar is wider than the window, extra buttons are behind the arrow at the right end
* Color names only match a small list, so some names are off (peach shows as Pink)

Expected next sprint:
* At least 3 unit tests
* Autosave on a timer
* Option to show or hide the autosave countdown, and reset the timer when the user saves
* Built in web server that shows one or more of the open images, chosen by the user, with a message when none are chosen
* Save an image in a different file format than the one it was opened in
* Warning that features or data can be lost when saving to a different format
* A test plan or demonstration that shows the format conversion and its data loss
* Fix the grabber, save dialog, and tool button issues above





Jacob's Paint Version 0.4.0 - 09/25/2026

Repository: https://github.com/jacobkirbyvalpo/CS250-Paint-Project
Release tag: https://github.com/jacobkirbyvalpo/CS250-Paint-Project/releases/tag/v0.4.0

New Features:
* Keyboard shortcuts: Ctrl+O open, Ctrl+S save, Ctrl+Shift+S save as, Ctrl+W close, Ctrl+Q exit
* Width slider now shows the current size in pixels.
* Tool buttons in the toolbar to switch between tools
* Pencil tool for freehand drawing
* Shape tools: rectangle, square, ellipse, circle, and triangle
* Shapes show a live preview while dragging and work in any drag direction
* Line width applies to shape outlines
* Dashed checkbox for dashed lines and shape outlines, dashes scale with line width
* Color label next to the color picker shows the name, hex code, and RGB value
* Color grabber tool, click the image to pick up that color for drawing
* Tabs, each opened image gets its own tab.
* Save, Save As, Close, and Resize work on whichever tab is selected
* Smart save checks each tab on close and every tab on exit (works with keybinds too).
* Refactored extensively
* JavaDoc comments

Known Issues:
* Nothing is drawn until an image is opened
* Line tool has no preview while dragging, it only appears on release
* Color names only match a small list, so some names are off (peach shows as Pink)
* Grabbing an empty spot gives black

Expected next sprint:
* Undo and redo using a stack
* Blank starting image so you can draw without opening a file
* Clear canvas tool with an "are you sure" check
* Another new shape
* Regular polygon with any number of sides
* Right and non-right angle triangles
* Select and copy/paste a piece of the image with live draw
* Select and move a piece of the image
* Add text typed in by the user
